# MVP do RadarClip AI

## Escopo do MVP
O MVP deve validar se é possível identificar tendências relevantes, gerar clipes curtos e disponibilizar esse fluxo para usuários autenticados.

## Funcionalidades essenciais
- Cadastro e login de usuários;
- Listagem de tendências;
- Upload de vídeos;
- Geração de clipes a partir de vídeos selecionados;
- Visualização de clipes gerados.

## Regras de negócio principais
- Somente usuários autenticados podem criar ou visualizar conteúdos relacionados;
- Cada vídeo pode estar associado a uma tendência;
- Cada clipe deve estar vinculado a um vídeo e a um usuário.

## Critérios de aceite do MVP
- O usuário consegue criar conta e autenticar-se;
- O usuário consegue enviar um vídeo;
- O sistema consegue gerar um clipe curto com base em regras de processamento definidas;
- O usuário consegue visualizar os clipes gerados.
