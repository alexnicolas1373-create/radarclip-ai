# Roadmap do RadarClip AI

## Objetivo
Definir as etapas iniciais para o desenvolvimento do MVP do RadarClip AI.

## Fase 1 - Fundação
- Definição da arquitetura e do escopo do MVP;
- Estrutura do repositório e separação entre frontend, backend e serviços de IA;
- Definição de requisitos funcionais e não funcionais.

## Fase 2 - Backend base
- Implementação da API REST;
- Autenticação e autorização com JWT;
- CRUD de usuários, tendências, vídeos e clipes;
- Modelagem do banco de dados.

## Fase 3 - Processamento de vídeo
- Integração com FFmpeg para corte de vídeos;
- Integração com serviços de IA para análise de tendências e sugestão de trechos;
- Pipeline para geração automática de clipes.

## Fase 4 - Frontend MVP
- Tela de autenticação;
- Dashboard inicial de tendências;
- Upload e listagem de vídeos;
- Visualização de clipes gerados.

## Fase 5 - Qualidade e operação
- Testes automatizados;
- Monitoramento básico;
- Deploy inicial;
- Ajustes com base em feedback dos usuários.
